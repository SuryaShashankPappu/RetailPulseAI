# RetailPulse AI - Source Systems

## Sales Transactions
Type: CSV
Source: Online Retail II Dataset
Purpose: Historical sales analytics and demand forecasting

## Inventory System
Type: PostgreSQL
Source: Operational Inventory Database
Purpose: Inventory tracking and stock-level analytics

## Supplier System
Type: REST API
Source: FastAPI Supplier Service
Purpose: Supplier metadata and lead-time analysis

## Customer Reviews
Type: JSON
Source: Review Documents
Purpose: Sentiment analysis and product quality insights

## Weather Data
Type: Public API
Purpose: Demand forecasting features

## Holiday Data
Type: Public API
Purpose: Seasonal demand forecasting

## Retail Events
Type: Kafka Streaming
Purpose: Real-time operational analytics
